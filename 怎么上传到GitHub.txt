============================================================

这个 zip 解压后就是网站全部文件，直接拖到 GitHub 就行。
地址：https://github.com/550513020/app

------------------------------------------------------------
第一步：解压
------------------------------------------------------------
把 GitHub上传包-P2K网页端.zip 解压到一个文件夹，
里面应该能看到 index.html、help.html、assets、scores 等。
（注意：要上传的是「解压后的内容」，不是 zip 本身）

------------------------------------------------------------
第二步：进入你的仓库
------------------------------------------------------------
浏览器打开：https://github.com/550513020/app
（如果提示登录，先登录你的账号 550513020）

因为仓库现在是空的，页面上会看到
「Quick setup — if you've done this kind of thing before」

------------------------------------------------------------
第三步：上传文件
------------------------------------------------------------
1. 点页面上的链接：uploading an existing file
   （或者点 Add file → Upload files）
2. 打开你解压出来的文件夹，全选里面的所有内容
   （Ctrl+A 全选，然后拖进浏览器页面中间的那个虚线框）
3. 等进度条走完（约 14 MB，视网速几十秒）
4. 拉到页面底部，点绿色按钮 Commit changes
5. 再等几秒，页面会显示你的文件列表

------------------------------------------------------------
第四步：开启网页访问（GitHub Pages）
------------------------------------------------------------
1. 在仓库页面上方点 Settings
2. 左侧栏找到 Pages（在 Code and automation 那一段里）
3. Source 选：Deploy from a branch
4. Branch 选：main     文件夹选：/ (root)
5. 点 Save
6. 等 1~2 分钟（首次要构建）

------------------------------------------------------------
第五步：打开看看
------------------------------------------------------------
网址：https://550513020.github.io/app/

手机版：https://550513020.github.io/app/?mode=app

------------------------------------------------------------
这个网页版能做什么（不需要你的电脑开着）
------------------------------------------------------------
· 找谱：列出仓库里的 PDF 琴谱，点「查看」直接看
· 音频库：从手机/电脑导入音频，在浏览器本机完成转谱，直接就能练
· 导入 PDF / 谱面图片，存本机离线可看
· 本机账号注册登录（只存这台设备）
· 练习 / 测试 / 音块模式全套

不能做的（需要电脑上的后端）：跨设备云端同步、AI 识谱(OMR)、Capella 全自动。
这些仍然在电脑本机那套里用。

------------------------------------------------------------
常见问题
------------------------------------------------------------
Q: 上传时提示文件太大？
A: 最大的文件是 index.html（约 5 MB），远低于 GitHub 的 25 MB 单文件上限，
   正常不会报错。若被中断，重试即可（支持续传）。

Q: 打开 https://550513020.github.io/app/ 显示 404？
A: Pages 还没构建完，等 1~2 分钟再刷新；
   或检查 Settings → Pages 里 Branch 是否选了 main、文件夹是否 / (root)。

Q: 想让手机直接扫码打开？
A: 手机浏览器打开 https://550513020.github.io/app/?mode=app 后，
   在浏览器菜单里选「添加到主屏幕」，就像 App 一样。
