# 谱键 P2K · 网页端

钢琴练习应用（网页端）。在线地址：

- 电脑：https://550513020.github.io/app/
- 手机：https://550513020.github.io/app/?mode=app

## 这个网页版能做什么

- **找谱**：列出仓库里的 PDF 琴谱，点「查看」直接看
- **音频库**：从手机/电脑导入音频，**在浏览器本机完成转谱**（引擎已内嵌，不需要服务器）
- **导入 PDF / 谱面图片**：存到本机，离线可看
- **练习 / 测试**：音块练习、测试评分、收藏片段

## 说明

托管在 GitHub Pages 上的是**纯静态网页**，所以没有后端的能力：
账号同步、云端曲库、识谱（OMR）需要在你自己的电脑上跑本地服务。
音频转谱因为在浏览器本机完成，所以在网页版里可以直接用。

本机完整版（含账号、云端、OMR、Capella）：双击电脑上的 `★启动我-双击这里★` 里的启动脚本。
