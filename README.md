# 谱键 P2K · 网页端

钢琴练习应用（纯网页版）。

- 电脑：https://550513020.github.io/app/
- 手机：https://550513020.github.io/app/?mode=app
- 使用说明（含二维码）：`help.html`

## 能做什么

- **找谱**：列出仓库里的 PDF 琴谱，点「查看」直接看
- **音频转谱**：导入音频，**在浏览器本机完成转谱**（引擎内嵌，无需服务器），转完直接练
- **导入 PDF / 谱面图片**：存本机，离线可看
- **本机账号**：注册登录只存在这台设备
- **练习 / 测试**：音块练习、测试评分、收藏片段

## 说明

这是**纯静态网页**，所以没有后端能力：
跨设备云端同步、AI 识谱（OMR）、Capella 全自动转谱需要在电脑上跑本地服务。
音频转谱因为在浏览器本机完成，所以在网页版里可以直接用。
